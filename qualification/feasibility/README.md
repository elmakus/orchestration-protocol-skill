    authority/credentials).

    from package-identity inputs; acyclic).

    `claim-fixtures.json`.
- `checks/` — non-inference local checks (no LLM, no Android, no remote):
  - `check-identities.mjs`, `check-csprng.mjs`, `check-metadata-leak.mjs`,
    `check-git-fencing.sh`, `run-all.sh`.

  explicit uncertainty (retrieval 2026-10-04; no live fetch performed).
